# guide — source and licence

The 70 rule files in this folder, and `_sections.md`, are an unmodified copy of the
`rules/` folder of the **vercel-react-best-practices** agent skill (version 1.0.0).

- **Upstream:** https://github.com/vercel-labs/agent-skills — `skills/react-best-practices/`
- **Author:** vercel — as declared in the skill's `SKILL.md`
- **Licence:** MIT — as declared in the skill's `SKILL.md` (`license: MIT`). On
  2026-10-11 the GitHub API reported no repository-level licence for the upstream
  repository, so that declaration is the only licence text there is to reproduce.
- **Copied:** 2026-10-11, from an installed copy of the skill; the upstream folder
  listed the same 70 rule files that day.

Nothing here is written by the owner of this repository. The day-by-day plan in
`docs/` and the site code are separate work and only quote rule titles.

Do not edit these files. A rule that changes upstream is replaced by a fresh copy,
so the text on the site always matches the source. Where a rule differs from the
Next.js version these sites run, the difference is recorded in `docs/00-rules.md`,
not here.

`_template.md` from the source is left out — it is a placeholder, not a rule.
