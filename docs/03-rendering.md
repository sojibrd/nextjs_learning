# ব্লক ৩ — Rendering

*দিন ০২৮–০৩৯ · rendering*

উৎসের সেকশন ৬ (*Rendering Performance*) — ১১টা rule, দিনে একটা; শেষ দিনে ⚑। Browser-এর কাজ কমানো — hydration, SVG, লম্বা তালিকা, script আর resource hint। ⚑-এর প্রশ্নটা ইন্টারভিউ-বিষয়গুলোর চতুর্থটা — event loop, rendering pipeline আর Core Web Vitals; এখানেও rule একটা অংশ ছোঁয়, বাকিটা আপনার নিজের উত্তর।

> **ব্লক শেষে:** ১১টা rule-এর প্রতিটায় না দেখে লেখা আর "কেন" ইংরেজিতে বলা হয়েছে, আর ⚑-এর উত্তর ২ মিনিটে মুখে এসেছে?
